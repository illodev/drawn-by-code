# References

Videos by other people that we study or replicate. **The videos are not committed**
(`references/*.mp4` is gitignored): they are someone else's work. This index is: what each
one is, which style it teaches, where it came from, and what we did with it. A replica
always credits its author (skill `replicate` → «Credit the original»).

To work on one, put the file back in this folder under the name below (from its source
link) and follow the skill `replicate`.
